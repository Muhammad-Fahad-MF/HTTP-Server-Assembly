About the Project

A modular course project implementing an HTTP/1.0 Web Server in MASM x86 Assembly.

  • Language: x86 Assembly (MASM)
  • Networking: Windows Winsock 2 (ws2_32.lib)
  • Terminal Output: Irvine32 Library
  • Supported Methods: GET (file serving) and POST (data submission)
